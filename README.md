# Cisco Packet Tracer

This repository contains my **Cisco Packet Tracer labs and networking practicals**.

I am using this repository to keep track of the different network configurations and experiments I work on while learning computer networking.

## Labs

- DHCP, DNS, Web Server and IP Helper
- More networking labs will be added here as I complete them.

## Tool Used

**Cisco Packet Tracer**

The `.pkt` files can be opened using Cisco Packet Tracer to view and test the network configurations.
